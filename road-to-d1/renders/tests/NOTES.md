## How to run the test
- Post both on the same platform within a day of each other, at a similar time.
- After 48–72 h compare, per clip: **average watch time %**, **shares/sends**, and **follows**.
  Shares/sends matter more than likes (that's what the algorithms weight most).
- One post each is a noisy test. If the results are close, it's a tie — post one more of each before deciding.
